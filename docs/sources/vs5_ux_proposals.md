## P-N3 되묻기 질문 3개 상한

### 지금

- 문장 분석 뒤 `missing`(빠진 필수 항목), `confirm`, `conflicts`, `unverified`를 각 줄에 모두 나열한다. 헬스장에서 문장이 짧으면 `missing`이 기간제로 확인된 경우 8개(`industry`, `contract_type`, `termination_cause`, `total_contract_amount`, `paid_amount`, `start_date`, `end_date`, `notice_date`), 계약 방식을 모르면 횟수 2개(`total_sessions`, `used_sessions`)가 더해져 10개까지 나온다 (`llm/extraction.py` `questions`).
- 폼에는 모든 칸이 그대로 있어, 질문 목록은 안내일 뿐 입력을 막지 않는다.

### 제안

- "더 필요한 정보"에는 **앞의 3개만** 보여 주고, 나머지는 "나머지 {n}개 항목은 아래 폼에서 입력해 주세요."로 접는다. 순서는 서버가 주는 `missing` 순서(필수 판정 순서: 업종 → 계약 방식 → 해지 사유 → 금액 → 날짜·횟수)를 그대로 쓴다. 화면이 순서를 다시 정하지 않는다.
- 3개 안에는 "모름"을 고를 수 있는 항목이면 선택지 안내를 붙인다 (해지 사유, 요가·필라테스 환급 기준, 환급 제한 조항, 연기 여부. 세탁은 소재·용도의 "모름"이 R1을 켤 때만).
- 각 질문 옆에 "이 칸으로 이동" 버튼을 둬 해당 폼 칸에 초점을 옮긴다 (키보드 조작 개선 포함).
- `confirm`(계산을 멈추게 하는 값)과 `conflicts`(입력한 값과 문장이 다름)는 상한에 넣지 않고 항상 모두 보인다. 사용자가 놓치면 결과가 달라지기 때문이다 **[제안]**.
- "모름"으로 답한 결과는 지금처럼 엔진이 🔍로 판정한다 (변경 없음).

## P-N8 업체 제시액과 기준 금액의 차액 표시

### 지금

- 헬스장: `provider_offer`가 시나리오 B 최솟값보다 작으면 ⚠️ `OFFER_BELOW_B`, B 최솟값 이상 A 최댓값 미만이면 안내 `OFFER_BETWEEN_A_AND_B`. 설명(`/api/guide`)에는 `OFFER_BELOW_B`일 때만 "업체 제시액 {offer}은 … 가장 작은 값 {min_b}보다 적습니다."가 들어간다. 차액은 없다.
- 세탁: 제시액이 4조합 최솟값보다 작으면 ⚠️ `OFFER_BELOW_STANDARD_MIN`. 차액은 없다.
- B가 없거나(정상가 미입력) 제시액이 A 최댓값 이상이면 아무것도 보이지 않는다 (MVP_SPEC 5.4 제시액 표). 2026-11-15 화면 확인: 제시액 30만 원, A 308,478원, B 없음 → 제시액 관련 표시 없음.

### 제안

1. **차액은 엔진이 계산한다.** 결과 모델에 정수 필드를 추가한다 **[제안]**:
   - 헬스장 `offer_comparison`: `offer`(입력 그대로), `min_b: int | None`, `max_a: int`, `min_a: int`, `gap_to_min_b: int | None` (= `min_b − offer`, 양수면 제시액이 더 적음), `gap_to_min_a: int` (= `min_a − offer`).
   - 세탁 `offer_comparison`: `offer`, `standard_min`(4조합 최솟값, 지금 `sensitivity_min`), `gap_to_min: int` (= `standard_min − offer`).
   - 계산은 `rules/gym.py`·`rules/laundry.py`의 순수 함수에서 하고, 표시 단계(`*_display.py`, 화면)는 받은 값만 쓴다. 테스트 기대값은 승인 케이스의 기존 금액과 입력 제시액에서 손계산한 값으로 새 케이스 보고서를 만들어 승인받은 뒤 넣는다.
2. 결과 카드 금액 아래에 "업체 제시액과 비교" 표를 둔다. 행: 업체 제시액 / 기준 금액(시나리오별 또는 범위) / 차이. 차이 열 문구는 부호에 따라 고정 문구를 고른다.
3. 배지 판정은 바꾸지 않는다. ⚠️는 지금처럼 강건한 비교(`OFFER_BELOW_B`, `OFFER_BELOW_STANDARD_MIN`)일 때만 켠다. 차액 표시는 정보일 뿐이다.
4. B가 없을 때(정상가 미입력): A 기준 차액만 보이고, "정상가 기준(B)으로 계산하면 기준 금액이 더 작아질 수 있어 이 차이는 줄어들 수 있습니다."를 붙인다 (기존 `NO_LIST_PRICE` 안내와 같은 뜻).
