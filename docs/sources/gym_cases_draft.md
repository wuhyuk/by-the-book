## 공통 계산식

```text
계약 일수   = 종료일 − 시작일 + 1
경과 일수   = 도달일 − 시작일 + 1, 단 0 이상 계약 일수 이하 (도달일 < 시작일 → 0)
기준 단위   = 기간 기준: 경과 일수 / 계약 일수,  횟수 기준: 이용 횟수 / 총 횟수
이용분_A    = 반올림(총계약대금 × 경과 ÷ 단위)       ← 원 단위 half up, 곱셈 먼저·한 번만 반올림
이용분_B    = 반올림(정상가 × 경과 ÷ 단위)           ← 정상가 ≥ 총계약대금일 때만
위약금 상한 = 내림(총계약대금 × 0.10)                 ← 원 미만 내림
위약금      = min(계약서상 위약금, 상한), 계약서상 위약금이 없으면 상한 (→ 최소 환급액)
환급액_X    = 지급 − 이용분_X − 부가상품 가액 − 위약금 + 반환한 부가상품 가치  (음수이면 0 + 안내)
보증금      = 전액, 환급액과 따로 표시
```

공통 입력: 따로 적지 않으면 소비자 사정 해지(`consumer`), 환급 제한·위약금 약정 있음, 부가상품 0, 보증금 0, 청약철회 미확인 (`withdrawal_cleared`가 true가 아님), 연기 없음. PT 여부(`is_pt_only`)는 헬스·피트니스 횟수제(S3, V2)에서만 묻고 나머지는 `None`.

공통 표시 (배지 판정과 무관한 안내): 계산 과정 첫 줄 단위대금 해석 고지, 이용분 줄 "원 단위 반올림(고시에 규정 없음)", 위약금 줄 "원 미만 내림(고시에 규정 없음)". 계약서상 위약금이 없으면 `PENALTY_INPUT_MISSING`·`STANDARD_TERMS_PENALTY` 안내. 연기 없음·미상이면 `PERIOD_CHECK` 안내. 청약철회 미확인이면 `WITHDRAWAL_INFO` 안내.
