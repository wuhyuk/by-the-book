### 3.5 계산과 배지

```text
W = max(고시 품질보증 개월, 보증서 품질보증 개월)
L = 12 × max(고시 부품보유 년, 보증서 부품보유 년)          ← 내용연수 (D-1, S13)
u = 구입일부터 접수일까지 완전한 개월 수 (D-5), 끝수가 있으면 +1 (D-4 올림)
결정 값 = floor( 구입가 − 구입가 × u ÷ L + 구입가 × 10 ÷ 100 ), 구입가를 넘으면 구입가 (D-6, D-7)
```

- 배지: ❔ → 🔍 계산 안 함 → ⚠️ `OFFER_BELOW_STANDARD_MIN`(제시액 < 8조합 최솟값, 쓰는 블록이 verified일 때만) → 🔍 (`PERIOD_BOUNDARY`, `PARTS_PERIOD_UNCONFIRMED`, `CERTIFICATE_UNCONFIRMED`, `RULE_UNVERIFIED`, `DECISION_SENSITIVE`) → ✅. 화면 우선순위도 이 순서 [제안].
- 쓰는 블록: `items`(해당 행), `lifespan_rule`, `depreciation`, `resolution_table`. 하나라도 `verified: false`이면 `RULE_UNVERIFIED`, ⚠️를 빼고 업체용 문안을 만들지 않는다 (2026-11-13 결정과 같음, A-32).
- 사용 개월은 접수일까지라 부품보유기간 안이면 u ≤ L이다 (제조일 ≤ 구입일). 잔여금이 음수가 되는 경우는 없다.
- 안내 `RECEIVED_DATE_BASIS` [제안] (계산한 결과에만): "기준상 품질보증기간이 지났는지는 수리를 사업자에게 접수한 날을 기준으로 판단합니다." (S7)
- 인용 (계산한 결과): `elec_5`, `elec_note_dep`, `elec_note_received`, `annex4`, `annex3_items`, (제조일 입력 시) `annex3_parts_start`, (보증서 기간 입력 시) `gen_4_ga`, `gen_4_ra`, `cpa16_3`. 표 카드(`annex3_items`, `annex4`)에는 "적용한 칸"(품목 행, 내용연수 개월, 사용 개월)을 덧붙인다 (2단계, 세탁 선례). ❔: `APPLIANCE_ITEM_NOT_SUPPORTED` → `annex4`, `PARTS_AVAILABLE` → `elec_5`, `WITHIN_WARRANTY` → `elec_5`, `annex3_items`, (보증서 보증기간 입력 시) `gen_4_ga`, `gen_4_ra`, `OUTSIDE_PARTS_PERIOD` → `elec_5`, `annex3_items`, `annex3_parts_start`. 모든 ID는 지금 규칙 JSON에 있다 (6절).

## 8. 승인 방법

- 케이스: "승인: A-1, A-2, …" 형식. 승인 전 확인 케이스(맨 앞 표)는 Q7·Q3 답과 함께 승인한다.
- 결정: "결정 기본값 그대로"(D-1~D-12) 또는 D 번호별로 다른 선택.
- 대조표: `appliance_verify_sheet.md`의 S1~S18 확인 결과(일치/불일치)를 알려 주면 2단계에서 `user_checked`와 `user_check_sheet.md`에 반영한다.
- 승인 전에는 어떤 값도 테스트 기대값으로 쓰지 않는다.
