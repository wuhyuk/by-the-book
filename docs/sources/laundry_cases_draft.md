## 공통 계산식

```text
사용일수   days = 세탁의뢰일 − 구입일   (구입 당일 = 0일, 대안 D1 = days + 1)
내용연수   평균 내용연수표 조회 (소재·용도별)
배상비율   배상비율표 [내용연수 행] 에서 사용일수가 속한 칸
배상액     floor(구입가격 × 배상비율 ÷ 100)   (대안: half up)
입증 불가  세탁요금 × 20
민감도     D0·D1 × 내림·half up 4조합의 (내용연수 행, 배상비율 칸, 배상액)이 모두 결과 값과 같으면 통과, 아니면 🔍 DECISION_SENSITIVE
```

공통 입력: 따로 적지 않으면 세탁소에 맡김(`laundry_shop`), 하자(`defect`), 제조 불량 주장 없음, 입증 가능(`proof_available = True`), Set 아님, 부속물 아님, 특약·감액·면책 주장 없음, 업체 제시액 없음.
