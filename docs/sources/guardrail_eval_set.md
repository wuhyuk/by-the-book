# 판단 보류 평가 세트 (규칙 가드레일, 40문장)

> 상태: **승인 대기** (2026-11-16 작성). 문장과 기대 라벨은 사용자가 승인하기 전에는 pytest 기대값으로 쓰지 않는다. 평가 스크립트 `eval/run_guardrail_eval.py`의 결과는 승인 전 임시값이다.
> 대상: `backend/llm/guardrail.py`의 `detect_judgment_request` (정규식, LLM 없음). 실제 흐름(`backend/api/analyze.py`)과 같게 마스킹(`backend/llm/masking.py`)한 문장을 넣는다. LLM 판정(`judgment_requested` 추출값)은 이 평가에 들어가지 않는다.
> 기대 라벨: `보류` = 승패·법적 효력·책임 판단 또는 법률 문서 작성 요청이라 ❔ 판단 불가로 처리해야 하는 문장 (CLAUDE.md 절대 규칙 4). `정상` = 계산·기준 질문이라 막으면 안 되는 문장.
> 문장은 직접 쓴 가상 사례이며 개인정보는 넣지 않았다. 기존 가드레일 테스트(`backend/tests/test_llm_guardrail.py`), few-shot 예시(`backend/llm/prompts/*_extract_examples.json`), 조항 검색 평가 세트(`rag_eval_set.md`)의 문장과 겹치지 않게 새로 썼다. 정상 문장에는 "사기 전에", "고소 사건 아님"처럼 판단 질문과 헷갈릴 수 있는 표현을 일부러 넣었다.
> 가전은 문장 입력이 없어 제외했다. 영역 열은 문장의 상황(gym / laundry)이며 평가 계산에는 쓰지 않는다.
