## 3. 확인 뒤 할 일

- 모두 일치: 2단계에서 쓰는 블록의 `verification.user_checked`를 `true`, `checked_at`을 확인 날짜로 바꾸고 `docs/sources/user_check_sheet.md`에 확인 행을 더한다. `source.retrieved_at`은 바꾸지 않는다.
- 하나라도 불일치: 그 값을 쓰는 블록은 `verified: false`로 두고 결과에 `RULE_UNVERIFIED`(🔍, 업체용 문안 없음)를 붙인다. 불일치한 항목과 원문 값을 알려 주면 케이스를 다시 계산한다.
