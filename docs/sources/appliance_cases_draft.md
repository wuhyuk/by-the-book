# 가전·전자제품 손계산 케이스 초안 (사전 조사, 검증 전)

- 작성일: 2026-11-02
- 상태: **10건 모두 검증 대기.** 사용자가 상태를 바꾸기 전에는 테스트 코드로 옮기지 않는다.
- 기준 문서: `appliance_spec_draft.md` (입력 A1, 범위 A2, 상황 A3, 기간 A4, 감가 A5, 배지 A6). 원문: `appliance_notice.md`, 시행령 별표 1: `dispute_standard_common.md`.
- 재계산: 감가 금액·개월 수·날짜 차를 서로 다른 두 계산기로 각각 계산해 일치를 확인했다 (2026-11-02). 스크립트는 저장소에 두지 않았다.
  - 방식 A: `datetime` + `Fraction`, 개월 수는 연·월 차에서 일자 비교로 보정
  - 방식 B: 율리우스일 정수식 + `Decimal`(`ROUND_FLOOR`, `ROUND_HALF_UP`), 개월 수는 `연×12+월` 차에서 일자 비교로 보정
- 모든 금액은 원 단위 정수. 가상 사례다.
- 원문에 없는 해석은 함께 적었다: 감가 환급 **X**(잔여금 + 구입가의 10%) / **Y**(잔여금 × 110%) [Q-A2], 사용 개월 1개월 미만 처리 [Q-A1], 기간 첫날·만료일 [Q-A5], 원 미만 **내림** / **half up** [Q-C1].
- 기대 배지는 **현재**(블록 모두 `verified: false`) / **결정·검증 후**(관련 질문이 정해지고 블록이 `true`) 두 칸.

## 공통 계산식

```text
기산일      교환일 > (판매일 미상이면) 제조일+3월 > 인도일(계약일과 다르면) > 구입일      ← 시행령 별표 1 4.라·마
보증기간    max(보증서 표시, 별표 Ⅲ)                                                      ← 4.가·나
내용연수    max(보증서 부품보유기간, 별표 Ⅲ 부품보유기간) × 12개월                         ← 별표 Ⅳ
감가상각비  구입가 × 사용개월 ÷ 내용연수개월                                              ← 별표 Ⅱ ① 비고
잔여금      구입가 − 감가상각비
환급 후보   X = 잔여금 + 구입가 × 10%,  Y = 잔여금 × 110%,  4) 분실은 한도 구입가
```

공통 입력: 따로 적지 않으면 새 제품, 정상 사용(`normal_use = True`), 보증서 기간 미입력(별표 Ⅲ 적용), 업체 제시 없음.

### A1. 구입 후 10일 경계 — 세탁기

- 입력: 품목 세탁기 / 구입·인도일 2026-10-01 / 접수일 2026-10-11 / 상황: 중요한 수리를 요하는 하자 (`major_repair = True`)
- 기간: 접수일 − 기산일 = **10일**. 첫날 불산입이면 10일 → "10일 이내" / 첫날 산입이면 11일 → 10일 초과
- 해결기준 후보:
  - 10일 이내로 보면: 1) **제품교환 또는 구입가 환급** (+ 2)의 "제품교환 또는 무상수리"도 해당 → 소비자 선택, 시행령 제9조 ③)
  - 10일 초과로 보면: 2) **제품교환 또는 무상수리**
- 사유 코드: `PERIOD_BOUNDARY`, `INTERPRETATION_DEPENDENT`, `RULE_UNVERIFIED`
- 안내: `CONSUMER_CHOICE`
- 기대 배지: 현재 **🔍** / 결정·검증 후 **✅** (Q-A5가 정해지면 하나)
- 검증 상태: 검증 대기

### A2. 보증서 기간이 더 김 + 유상수리 요구 — 냉장고

- 입력: 품목 냉장고 / 구입·인도일 2025-03-10 / 보증서 품질보증기간 24개월 / 접수일 2026-08-01 / 상황: 하자 발생 / 업체 안내: 유상수리
- 보증기간: 별표 Ⅲ 1년 < 보증서 2년 → **24개월** (4.가). 만료일 후보 2027-03-09 또는 2027-03-10 → 접수일은 어느 쪽이든 **이내**
- 해결기준: 3) **무상수리**
- 비교: 업체가 유상수리를 요구 → 모든 기간 해석에서 보증기간 이내, 정상 사용
- 사유 코드: 현재 `RULE_UNVERIFIED` (⚠️ `PAID_REPAIR_IN_WARRANTY`는 블록 미검증이라 뺌) / 결정·검증 후 `PAID_REPAIR_IN_WARRANTY`
- 기대 배지: 현재 **🔍** / 결정·검증 후 **⚠️**
- 검증 상태: 검증 대기

### A3. 보증기간 경과 후 수리 불가, 감가 환급 — 세탁기

- 입력: 품목 세탁기 / 구입가 1,200,000 / 구입·인도일 2024-01-15 / 정산 기준일 2026-07-15 / 상황: 수리 불가 (보증기간 1년 경과 후)
- 내용연수: 별표 Ⅲ 부품보유기간 7년 → **84개월** / 사용: **30개월** (일 단위 나머지 없음)
- 감가상각비: 1,200,000 × 30 ÷ 84 = 428,571.43 / 잔여금: 771,428.57
- 환급 후보:
  - X: 771,428.57 + 120,000 = 891,428.57 → 내림 **891,428** / half up **891,429**
  - Y: 771,428.57 × 1.1 = 848,571.43 → **848,571** (두 방식 같음)
- 부품보유기간 안 (30 < 84개월) → 각주 2) 충족
- 사유 코드: `ADD_ON_DEPENDENT`, `ROUNDING_DEPENDENT`, `INTERPRETATION_DEPENDENT`, `RULE_UNVERIFIED`
- 기대 배지: 현재 **🔍** / 결정·검증 후 **✅**
- 검증 상태: 검증 대기

### A5. 분실, 한도 구입가 — 냉장고 (보증서 부품보유기간 15년)

- 입력: 품목 냉장고 / 구입가 2,000,000 / 구입·인도일 2025-09-01 / 보증서 부품보유기간 15년 / 정산 기준일 2026-10-01 / 상황: 수리 맡긴 제품을 업체가 분실 (보증기간 1년 경과 후)
